What this does and does not cover

State lines are generalized Census boundaries. The MISO boundary is a planning footprint; New York uses a state proxy. PAD-US includes varied designations, not all prohibited areas. The supplied data do not cover all land rights, parcels, floodplains, tribal areas, or permits. The route uses a limited search area. This is not a siting study.
