# Interconnection planning preview

This preview combines the existing local PYORPS routing application with project-feature competing-risk historical scenarios. It is not a production-calibrated forecast. The public preview is separate from the existing Queue Atlas site.

## Run and test

From this directory, run `python -m uvicorn app:app --host 127.0.0.1 --port 8769` in the existing `pyorps-env`, with the GIS bundle in `~/Downloads/PYORPS_MISO_NYISO_Data` or `PYORPS_DATA_DIR`. Run `npm test` for JavaScript syntax and probability invariants. `python prepare_dashboard.py` generates the Cloudflare preview bundle; run `cf deploy --prebuilt --dry-run` and `cf deploy --prebuilt` from `dashboard-deployment`.

## Timeline models

The browser runs separate MISO and NYISO histogram-gradient-boosted quarterly models, trained on project age, capacity and technology from observations through 2025Q4. MISO predicts IA, withdrawal or remaining in the queue; NYISO combines IA and operation. Quarterly transition probabilities are accumulated as competing risks over five years. For existing projects age advances from the evaluation date; technology and capacity remain fixed.

`scenario-models.json` exports the trusted research models; `scenario-model.js` evaluates their decision trees. `scenario-model-fixtures.json` was generated by the original Python models; `scenario-model.test.cjs` compares 350 scenarios against that reference. The research and tests are described in `TEN-MODEL-RESULTS.md`. The user requested these exploratory models as the main estimates; they remain unsuitable for decision-grade forecasts because historical input vintages, censoring and subgroup calibration have not been resolved. NYISO substantially underestimated withdrawals during the 2024–2025 transition. Five-year outcomes have less recent validation. No storage MW, service type, POI or route-cost input is used in timeline predictions.

## Routing and data

The POI coordinates come from the existing MISO mapped POI file; they do not establish electrical feasibility or interconnection availability. The NYISO planning boundary is a state proxy, and no verified NYISO POI layer is supplied. NYISO supports a manually selected route endpoint and a user-supplied per-mile rate. Route geometry comes from PYORPS over the local GIS cost surface; the line estimate multiplies route length by MISO MTEP24 state/voltage rates or the entered rate. It excludes separate substations and network upgrades. Routing preferences are not dollars. The search buffer and source coverage limit route quality.

The public preview proxies routing requests to `pyorps-backend.onrender.com`. The service can take time to wake and may fail while starting. It is not an independently tested high-availability production deployment. OSM tiles are requested from OpenStreetMap and the browser displays their attribution.
